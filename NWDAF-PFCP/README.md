# PFCP-NWDAF Detection Framework

This repository contains four standalone Python implementations for PFCP attack detection:

1. PFCP Flooding and Malformed Packet Detection
2. PFCP Session Hijacking and Unauthorized Session Deletion Detection
3. Coordinated Fragmentation Attack Detection
4. Delayed Fragmentation Attack Detection

These scripts are proof-of-concept implementations intended for research and NWDAF integration.
